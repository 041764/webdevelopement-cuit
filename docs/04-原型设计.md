# 原型设计（文字版）

> 目标：给前端一个“可落地的页面-接口映射”，不做视觉稿，只列信息架构与关键交互。

## 1. 登录页
- 选择身份：学生 / 教师
- 输入：账号（user_no）、密码
- 提交：`POST /auth/login`
- 成功：保存 access/refresh；进入首页

## 2. 首页（按角色）
### 2.1 学生
- 我的活动：列表（可筛选 term）
  - 列表：`GET /activities`
  - 报名：`POST /activities/{id}/signups`
  - 取消：`DELETE /activities/{id}/signups/me`
- 我的计划：
  - 列表：`GET /plans`
  - 新建：`POST /plans`
  - 条目新增/状态切换：`POST /plans/{id}/items`、`PATCH /plans/{id}/items/{itemId}`

### 2.2 教师/管理员
- 用户导入：
  - 上传 CSV：`POST /users/import`
  - 展示统计：created/updated/failed 与失败明细
- 活动管理：
  - 创建：`POST /activities`
  - 发布：`POST /activities/{id}/publish`
  - 报名审核：`GET /activities/{id}/signups`，通过/拒绝：`POST /activities/{id}/signups/{signupId}/approve|reject`
- 评价管理：
  - 创建评价：`POST /evaluations`
- 报表：
  - 计划完成率：`GET /reports/plan-completion`
  - 活动报名统计：`GET /reports/activity-stats`

## 3. 数据字典页（可选）
- 学院列表：`GET /colleges`
